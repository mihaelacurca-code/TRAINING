# Variante de produs

Trei orientări distincte ale platformei. Fiecare variantă este un **overlay** peste `../01-master-prompt-platform.md`: se copiază promptul master, apoi se adaugă blocul din varianta aleasă.

| Variantă | Pentru cine | Accent |
|---|---|---|
| `a-imm-web-platform.md` | IMM-uri, self-service | autonomie, cost zero/redus, rezultat în 90 de zile |
| `b-institutional-stakeholders.md` | autorități, instituții publice, asociații sectoriale | coordonare, supraveghere, exercițiu sectorial, raportare |
| `c-mixed-training-simulation-maturity.md` | operatori mari, consultanți, centre de training | trei zone: training + simulare + evaluare de maturitate |
